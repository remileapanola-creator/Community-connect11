About this Admin Panel

Use the menu on the left to manage community information. Everything you add, edit, or delete is saved in the browser's LocalStorage and shown on the public website right away.

Example flow:

Admin adds announcement → saved to LocalStorage → user opens Announcements page → new announcement appears.
