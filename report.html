03

Key Features

Public Website

Home, News, Announcements, Events (RSVP + Calendar), Activities, Gallery, Global Search, Emergency Hotlines, News AI Assistant, About, Contact.

Resident Dashboard

Certificate Requests (Indigency, Clearance, Residency, Good Moral, Business Clearance), Incident Reports, Community Feed (Lost & Found), My Profile, Emergency Alert Popup with 30-second alarm + AI voice.

Official Dashboard

Certificate request review (approve / reject / print A4 certificate), Incident response (claim / updates / resolve), community feeds, notification bell filtered by All / Incidents / Certificates.

Admin Dashboard

Content CRUD, Manage Users, Comments moderation, Go Live studio, Emergency Broadcast studio, Settings (backup / restore), audit log.

04

Go Live Streaming

Real-time camera & microphone broadcast from the admin to residents on other computers.

  • Transport: WebSocket relay via server.js for LAN cross-device streaming
  • Fallback: BroadcastChannel for same-browser use when no server is running
  • Viewer experience: LIVE badge, live viewer count, running duration, stall watchdog
  • Recording: Optional save to IndexedDB (Live Archives)
  • Run: node server.js
05

Emergency Broadcast

  • Admin publishes alert to one barangay or all barangays with expiry
  • Instant EMERGENCY ALERT popup on matching dashboards
  • 30-second Web Audio alarm + AI voice reads description aloud
  • STOP ALARM silences own device only; REPEAT ANNOUNCEMENT available
  • Popup stays until admin resolves or expires
06

Certificate & Incident Services

Certificate Requests

Resident selects barangay (only admin-created barangays appear), chooses type, gets reference number (e.g., CC-2026-12345), tracks status Pending → Ready → Released. Officials print A4 certificate and export release-log CSV.

Incident Reports

Residents report type, severity, location, description, photo, GPS/landmark. Reference number (e.g., INC-2026-12345). Status: Reported → Responding → Resolved. Notifies all officials. Escalation after 15 minutes.

How to Run

PWA / HTTP

Go Live Streaming

node server.js → Admin: http://localhost:8787/admin.html
